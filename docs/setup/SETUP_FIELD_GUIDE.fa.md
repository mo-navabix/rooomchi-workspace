# راهنمای فیلدهای ویزارد Setup

نسخهٔ قابل دانلود (PDF): پس از `npm run docs:setup-pdf` در مسیر `public/docs/setup-field-guide.pdf`  
نسخهٔ HTML: `public/docs/setup-field-guide.html` — از صفحهٔ خوش‌آمدگوی `/setup` لینک دانلود دارد.

محتوای کامل فیلدها در همان فایل HTML/PDF است؛ برای ویرایش متن، `public/docs/setup-field-guide.html` را به‌روز کنید و دوباره `npm run docs:setup-pdf` بزنید.
